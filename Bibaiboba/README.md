# Bibaiboba

**Bibaiboba** — Android-приложение-помощник на базе ИИ (Kotlin + Jetpack Compose).

## Что умеет

- **ИИ-чат**: ответы на вопросы, помощь с задачами, идеи, тексты, объяснения.
- **Управление телефоном**: открытие приложений, поиск, карты, звонки/набор номера, таймеры, будильники, системные настройки, шаринг/копирование.
- **Команды на естественном языке**: например `открой YouTube`, `поставь таймер на 5 минут`, `поставь будильник на 7:30`, `найди погоду в Москве`.
- **Действия от ИИ**: модель может возвращать action-тег, который приложение выполняет на устройстве.
- **Настройки**: Base URL, API key, модель, имя пользователя, персона ассистента, переключатели анимаций/виброотклика.
- **UI-эффекты**: анимированный неоновый фон, glassmorphism-карточки, градиенты, анимированный индикатор печати, современный тёмный интерфейс.

## Важно про API-ключ

API-ключ, который вы передали при создании проекта, уже подставлен как значение по умолчанию в `gradle.properties` (`BIBAIBOBA_API_KEY`) и попадает в `BuildConfig`.  
Его можно заменить в настройках приложения после установки.

## Как собрать APK

### Вариант 1 — GitHub Actions (самый простой)

1. Создайте репозиторий на GitHub и загрузите содержимое папки `Bibaiboba`.
2. Откройте вкладку **Actions**.
3. Запустите workflow **Build Bibaiboba APK** (или просто сделайте push в `main`).
4. После сборки скачайте артефакт **Bibaiboba-debug-apk** — внутри будет `app-debug.apk`.

### Вариант 2 — Android Studio

1. Откройте папку `Bibaiboba` в **Android Studio** (Hedgehog+ / Koala+ / Ladybug+).
2. Дождитесь Gradle Sync.
3. Выберите **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 3 — командная строка

Требования: JDK 17+, Android SDK, Gradle 8.7+ (или wrapper).

```bash
cd Bibaiboba
gradle wrapper --gradle-version 8.7   # если gradlew отсутствует
./gradlew :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Разрешения и управление телефоном

Базовые действия работают через Android intents:

- открыть приложение/ссылку/карту/поиск;
- набрать номер;
- поставить таймер/будильник;
- открыть системные настройки;
- поделиться текстом / скопировать в буфер.

Для более глубокой автоматизации (жесты/нажатия внутри других приложений) приложение содержит `AccessibilityService`. Пользователь включает его вручную в настройках Android:  
**Настройки > Специальные возможности > Bibaiboba**.

## Настройка ИИ API

По умолчанию проект настроен на OpenAI-compatible endpoint:

- Base URL: `https://api.openai.com/v1/`
- Model: `gpt-4o-mini`
- API Key: значение из `gradle.properties` / настроек приложения

Если ваш ключ относится к другому OpenAI-compatible провайдеру, измените Base URL и модель в настройках.

## Безопасность

- Не публикуйте реальный API-ключ в публичном репозитории.
- Для продакшена перенесите ключ в `local.properties`, секреты CI или backend-proxy.
- Debug APK подходит для тестирования; для релиза настройте signing config.
